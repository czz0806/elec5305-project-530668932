ELEC5305 Final Project - Audio Data Provenance

Source: Microsoft Deep Noise Suppression (DNS) Challenge
Official repository: https://github.com/microsoft/DNS-Challenge
Dataset location: datasets/test_set/synthetic/no_reverb/

The final controlled benchmark uses eight aligned 10-second, 16 kHz,
single-channel clean/noisy pairs. The noisy filenames identify the original
DNS noise category and the clean filename shares the same file ID.

Experimental use
----------------
For each aligned pair, the original residual noise is calculated as

    residual noise = DNS noisy recording - DNS clean recording.

The residual is then scaled and remixed with the clean reference at four
controlled input SNRs: -5, 0, 5 and 10 dB. This gives 32 test conditions.
The same aligned clean reference and residual noise are used for both methods,
so method comparisons are paired and reproducible.

Important scope limitation
--------------------------
The final benchmark uses an oracle noise-power estimate derived from the known
aligned noise residual. This design isolates the different spectral gain rules
used by Wiener filtering and spectral subtraction. It does not represent a
causal real-time system, where the clean signal and exact noise are unavailable.
